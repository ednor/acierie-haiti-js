# Aciérie d'Haïti - Site Web Officiel

Ce projet est le site web officiel de l'**Aciérie d'Haïti**, une entreprise spécialisée dans les matériaux de construction et les solutions métallurgiques en Haïti depuis 1972.

## 🚀 Fonctionnalités

- **Accueil Dynamique** : Présentation de l'entreprise, statistiques clés et aperçu des produits et projets.
- **Catalogue de Produits** : Recherche et filtrage par catégorie des matériaux (acier, fixation, structure, bois, etc.).
- **Demande de Devis** : Système de panier permettant aux utilisateurs de sélectionner des produits et d'envoyer une demande d'informations ou de devis via un formulaire ou WhatsApp.
- **Portfolio de Projets** : Présentation des réalisations types avec des détails interactifs.
- **Design Responsif** : Expérience utilisateur optimisée pour tous les terminaux (mobile, tablette, desktop) via Bootstrap 5.
- **Animations au défilement** : Utilisation d'Intersection Observer pour des apparitions fluides des éléments.

## 🛠️ Technologies Utilisées

- **HTML5 / CSS3** : Structure et mise en page personnalisée.
- **JavaScript (ES6+)** : Logique client, gestion du panier local, et animations.
- **Bootstrap 5** : Framework CSS pour le layout et les composants UI.
- **Bootstrap Icons** : Bibliothèque d'icônes.
- **Google Fonts** : Typographie (Inter).

## 📂 Structure du Projet

```text
.
├── index.html            # Page d'accueil
├── a-propos.html        # Histoire, mission et valeurs
├── produits.html         # Catalogue interactif des produits
├── projets.html          # Réalisations et études de cas
├── contact.html          # Formulaire de contact général
├── demande-devis.html    # Formulaire de demande de devis spécifique
├── css/
│   └── style.css         # Styles personnalisés
├── js/
│   └── script.js        # Scripts de comportement (panier, animations, etc.)
└── images/               # Assets graphiques et photos
```

## 🔧 Installation et Utilisation

1. Clonez le dépôt.
2. Ouvrez `index.html` dans votre navigateur ou utilisez une extension "Live Server".
3. Le projet ne nécessite aucune étape de compilation ou d'installation de dépendances côté serveur.
